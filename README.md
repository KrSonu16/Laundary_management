# Laundry Management System

A full-stack Laundry Management application built with Next.js, React, Tailwind CSS, TypeScript, and Drizzle ORM.

## Setup & Installation

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Configure environment variables:
   - Copy `.env.example` to `.env` in root and `backend/` as required.

3. Run development servers:
   ```bash
   # Run frontend
   pnpm dev

   # Or run workspace projects as configured
   ```
